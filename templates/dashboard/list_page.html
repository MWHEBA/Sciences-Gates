{% extends "dashboard/base.html" %} {% load static %} {% comment %} CRUD List Page Template Pattern - نمط قالب صفحة قائمة CRUD ============================================================ A reusable template pattern for displaying, searching, and filtering collections of content items. Follows a consistent vertical structure: page header, filter bar, data table, pagination. This template is designed to be extended by specific list pages (articles, universities, etc.) and provides a standardized layout that implements all design system requirements. Structure: 1. Page Header (topbar with title + "Add New" button) 2. Empty State (if no items exist) 3. Filter Bar (if items exist) 4. Data Table (if items exist) 5. Pagination (if items exist and exceed 20 per page) Context Variables (required): - page_title: str - Page heading text (e.g., "المقالات") - page_description: str - Subtitle/description text - action_buttons: list - Action buttons for topbar (optional, but recommended for "Add New") Each button: {url, label, variant} variant: "primary" | "secondary" | "danger" | "ghost" - items: QuerySet - List of items to display - search_placeholder: str - Placeholder text for search input - search_value: str - Current search query value - base_url: str - Base URL for filter reset - filters: list - Filter definitions (optional) - columns: list - Column definitions for data table - edit_url_name: str - URL name for edit action - delete_url_name: str - URL name for delete action - is_paginated: bool - Whether pagination is enabled - page_obj: Page - Django paginator page object - query_params: str - Preserved query parameters for pagination Context Variables (optional): - empty_state_icon: str - SVG icon for empty state - empty_state_heading: str - Empty state title (Arabic) - empty_state_description: str - Empty state description (Arabic) - filtered_empty_state_heading: str - Heading when filters return no results - filtered_empty_state_description: str - Description when filters return no results Requirements: 6.1, 6.2, 6.3, 6.4, 6.5, 6.6, 6.7, 6.8 Usage Example (in view): from django.urls import reverse from django.core.paginator import Paginator def article_list(request): articles = Article.objects.all() # Search search_query = request.GET.get('search', '') if search_query: articles = articles.filter(title__icontains=search_query) # Pagination (20 items per page) paginator = Paginator(articles, 20) page_number = request.GET.get('page', 1) page_obj = paginator.get_page(page_number) # Build query params for pagination query_params = '&'.join([f'{k}={v}' for k, v in request.GET.items() if k != 'page']) context = { 'page_title': 'المقالات', 'page_description': 'إدارة جميع المقالات', 'action_buttons': [ { 'url': reverse('dashboard:article_create'), 'label': 'إضافة مقالة جديدة', 'variant': 'primary', } ], 'items': page_obj.object_list, 'search_placeholder': 'ابحث عن عنوان المقالة...', 'search_value': search_query, 'base_url': reverse('dashboard:article_list'), 'filters': [ { 'name': 'status', 'label': 'حالة النشر', 'options': [ {'value': 'published', 'label': 'منشور'}, {'value': 'unpublished', 'label': 'غير منشور'}, ], 'selected': request.GET.get('status', ''), }, ], 'columns': [ {'label': 'العنوان', 'key': 'title', 'type': 'link', 'link_url_name': 'dashboard:article_edit', 'link_param': 'id'}, {'label': 'الحالة', 'key': 'is_published', 'type': 'badge', 'badge_status_key': 'is_published'}, {'label': 'التاريخ', 'key': 'created_at', 'type': 'date'}, ], 'edit_url_name': 'dashboard:article_edit', 'delete_url_name': 'dashboard:article_delete', 'is_paginated': paginator.num_pages > 1, 'page_obj': page_obj, 'query_params': query_params, } return render(request, 'dashboard/list_page.html', context) {% endcomment %} {% block title %}{{ page_title }} -
